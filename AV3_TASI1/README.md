# 📌 Ollama Embeddings Script
Esse repositório é refente a AV3 da matéria de TASI 1, contendo um script Python para gerar tokens e embeddings de uma frase usando o Ollama localmente.
Lembrar de retirar as aspas simples '' na execução dos codigos no terminal.

## 🔧 Pré-requisitos!
- Ollama instalado (https://ollama.com/download)
- Modelo 'nomic-embed-text' baixado 
    (rode no terminal 'ollama pull nomic-embed-text')
- Python 3 + pip
- Biblioteca 'requests' instalada: 'pip install requests'
    (rode no terminal 'pip install requests')

## 🚀 Como executar?
1. Inicie o Ollama executando no seu terminal: 'ollama serve'
2. Baixe o arquivo 'av3_script.py'
3. Abra no terminal o diretório onde o arquivo .py está localizado: 'cd C:\Users\seu_user\...\...\...\'
4. Execute o arquivo .py no terminal: 'python av3_script.py'
5. Prontinho! =p
